Are you new to HTML? Well, this is for you!

This will go over all of the HTML tags and how to utilize them.

The head tag is important, this is where the <title> element goes alongside your stylesheet.

This is an example of a stylesheet, which goes underneath the <head> tag

To conclude this section, essential things such as stylesheets, webpage tites, imported scripts, ect.

<BODY>

The body tag is where the main parts code go.

The body tag is simply where everything goes as shown here:

<div class="element">

Unlike other tags, the div tag serves as a way to impliment a custom element. The div tag gives your desired section a different name.

An example of this is shown here:

<div class="element">

<p>This text is inside of an element.</p>

<img src="hi.jpg">

</div>

</div>

</BODY>

<STYLE>

This tag, though is HTML, contains CSS. CSS stands for Cascading Style Sheets which determines the style of a website. A CSS file can also be imported as shown here:

<link href="yourstyle.css" rel="stylesheet" type="text/css" media="all">

Underneath the style tag, you can determine the background color, border color, font-style, the margins of a block of text. For more information about CSS, click the CSS tab.

</STYLE>

</HTML>
