CSS

CSS, meaning Cascading Style Sheet, is what determines the look and feel of a website.

In this section, I will be going over various CSS elements and displaying them.

:ROOT {

/*The root is what is reffered to as a "pseudo class" that matches the <html> element, which goes before all the other elements.*/

--text: #000000;

--border: #00be37;

--outline: #003ebe;

--background: #004dbe

--gradient-top: #c9d771;

--gradient-bottom: #62700e;

}

BODY {

background-color: #abc3ff; /* This dictates the background color of the webpage */

color: #535353; /* This dictates the font color */

}

P {

/* "P" being short for a paragraph/block of text. This dictates the style of the text as shown here. */

color: #181818;

font-size: 14px;

font-family: "courier new";

}

LI {

list-style-type: square;

}
