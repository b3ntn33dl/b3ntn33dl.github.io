CSS

CSS, meaning Cascading Style Sheet, is what determines the look and feel of a website.

In this section, I will be going over various CSS elements and displaying them.

* {

/* Other filters include, invert, contrast and hue-rotate. */

/* there are several preset cursor styles such as 'help', 'not-allowed', 'cell' and many others. You can also add custom cursors via images. */

}
