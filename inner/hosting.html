Hosting

When it comes to choosing which platform to host your site on, there's a lot of options though, you're never quite sure it's the best option for what you're looking for.

⚠ DISCLAIMER: this showcases site hosters I've personally used, sorry.

    Neocities

    Unarguabily the most popular, neocities is a good way for those who are beginners to get in to site building and is easy to navigate.

    PROS:

  • Easy to use
  • 1 GB storage
  • Makes it easy for others to discover new sites

    • CONS:

  • Limited file types allowed (.html, .htm, .jpg, .png, .gif, .svg, .ico .md, .markdown, .js, .json, .geojson, .css, .txt, .text, .csv, .tsv, .xml, .eot, .ttf, .woff, .woff2, .svg)
  • Not entirely free (6USD for supporter)
  • Inability to support certain site widgets (i.e status cafe)

Nekoweb

A newer Neocities alternative created in 2022, it has steadily grown popular over the years for being open source and community.

    PROS:

  • A lively community consisting of creatives
  • Discoverable sites on the front page
  • More customizable compared to Neocities

    • CONS:

  • Not entirely free (3USD for supporter)
  • 500MB of storage on free tier (not much if you have a larger site)

Github

Github, primarily a file hosting platform, is also a site hoster and allows a wide arrange of file types and sizes.

    PROS:

  • Supports a wide array of file types including , .doc , .docx , .gdoc, C+ and C++ just to name a few. To see every file type supported go here
  • Completely free!
  • Registering a custom domain is easy compared to other hosters

    • CONS:

  • Not the best option for the ultimate beginner.
  • Takes a while to get used to if you've never used it before
